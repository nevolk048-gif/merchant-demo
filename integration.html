1️⃣ Настройка

ℹ️ Получите API ключ из базы данных:
SELECT api_key FROM casinos WHERE name = 'Your Casino';

2️⃣ Создание депозита

POST /transactions/deposit

Request Headers

Content-Type: application/json X-API-Key: your_api_key

Request Body

{ "amount": 200, "currency": "RUB", "country": "RU", "player_id": "player_123", "external_id": "your_internal_id", "merchant_customer_id": "customer_123", "payment_method": "auto" }

Response

{ "transaction_id": "uuid", "status": "WAITING_PAYMENT", "requisite": { "bank_name": "Сбербанк", "holder_name": "Иван И.", "account_number": "1234 5678 9012 3456" }, "provider": { "id": "uuid", "name": "MajorPay" } }

3️⃣ Проверка статуса

GET /transactions/:id

Request Headers

X-API-Key: your_api_key

Response

{ "id": "uuid", "status": "PAID", "amount": 200.0, "currency": "RUB", "country": "RU", "created_at": "2026-06-08T10:00:00Z", "paid_at": "2026-06-08T10:05:00Z" }

Возможные статусы

Статус Описание
NEW Транзакция создана
WAITING_PAYMENT Ожидает оплаты (показаны реквизиты)
PAID Успешно оплачено
EXPIRED Истёк срок оплаты
CANCELLED Отменено

4️⃣ Webhook уведомления

PaymentsGate отправляет webhook при изменении статуса транзакции.

Формат webhook

POST your_webhook_url
{ "type": "payment.success", "object": { "uuid": "transaction_id", "status": "PAID", "amount": 200.0, "external_id": "your_internal_id" }, "secret_key": "your_casino_secret" }

Headers

X-Major-Timestamp: 1780913490 X-Major-Signature: hmac_sha256_signature Content-Type: application/json
⚠️ Всегда проверяйте подпись X-Major-Signature для защиты от подделок!

Проверка подписи (PHP)

$timestamp = $_SERVER["HTTP_X_MAJOR_TIMESTAMP"]; $signature = $_SERVER["HTTP_X_MAJOR_SIGNATURE"]; $rawBody = file_get_contents("php://input"); $payload = json_decode($rawBody, true); $txId = $payload["object"]["uuid"]; $secretKey = "your_casino_secret_key"; // Generate expected signature $dataToSign = $timestamp . "." . $txId . "." . $rawBody; $expected = hash_hmac("sha256", $dataToSign, $secretKey); if (!hash_equals($expected, $signature)) { http_response_code(401); exit("Invalid Signature"); } // Process webhook...

5️⃣ Примеры кода

JavaScript (Fetch API)

const response = await fetch('https://api.example.com/api/v1/transactions/deposit', { method: 'POST', headers: { 'Content-Type': 'application/json', 'X-API-Key': 'your_api_key' }, body: JSON.stringify({ amount: 200, currency: 'RUB', country: 'RU', player_id: 'player_123' }) }); const data = await response.json(); console.log(data);

Python (Requests)

import requests response = requests.post( 'https://api.example.com/api/v1/transactions/deposit', headers={ 'Content-Type': 'application/json', 'X-API-Key': 'your_api_key' }, json={ 'amount': 200, 'currency': 'RUB', 'country': 'RU', 'player_id': 'player_123' } ) data = response.json() print(data)

cURL

curl -X POST https://api.example.com/api/v1/transactions/deposit \ -H "Content-Type: application/json" \ -H "X-API-Key: your_api_key" \ -d '{ "amount": 200, "currency": "RUB", "country": "RU", "player_id": "player_123" }'
