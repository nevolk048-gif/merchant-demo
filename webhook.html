Инструкция по настройке

1. Локальная разработка (с ngrok)

$ ngrok http 3000

Скопируйте HTTPS URL (например, https://abc123.ngrok.io) и используйте его как webhook URL

2. Обновите настройки казино

UPDATE casinos SET webhook_url = 'https://your-domain.com/api/webhooks/paymentsgate' WHERE id = 'your_casino_id';

3. Реализуйте endpoint

Создайте POST endpoint по указанному URL, который:

  • Проверяет подпись X-Major-Signature
  • Обрабатывает событие (обновляет баланс, статус заказа и т.д.)
  • Возвращает 200 OK
